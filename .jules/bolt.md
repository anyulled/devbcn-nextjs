## 2025-07-02 — O(N) Object.entries() to O(1) Property Access in Navigation
**Learning:** `Object.entries(obj).find(([key]) => key === target)?.[1]` is a common pattern in the codebase but creates an O(N) bottleneck, particularly when fetching navigation or conditions dynamically where it is called for every nav item. TypeScript sometimes forces this pattern for type safety, but the `as keyof typeof obj` cast safely circumvents it.
**Action:** Replace `Object.entries().find()` with direct property access like `obj[target as keyof typeof obj]` whenever key lookups are performed dynamically on known objects, removing O(N) linear search overhead and array allocation.
