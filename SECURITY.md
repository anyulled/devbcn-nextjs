# Security Policy

## Supported Versions

Only the latest `main` branch is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please responsibly disclose it by contacting the repository maintainers. Do not open public issues for security vulnerabilities.

The `CODEOWNERS` file lists the individuals responsible for reviewing and merging code, particularly around security-critical paths such as caching logic, analytics, and dependencies.
